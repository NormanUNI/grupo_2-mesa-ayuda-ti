# Catalogo de software autorizado

El catalogo de software autorizado lista las aplicaciones que pueden instalarse sin
evaluacion adicional. Incluye la suite ofimatica, el navegador corporativo, el
cliente de VPN, el agente de seguridad y las herramientas de disenio y analisis
aprobadas por cada area.

La instalacion se realiza desde el portal de aplicaciones. Las estaciones de
trabajo no permiten instalaciones con privilegios de administrador local.

Para solicitar software fuera del catalogo se abre un ticket con la justificacion
funcional, el proveedor y el modelo de licenciamiento. La evaluacion toma hasta
diez dias habiles e incluye revision de seguridad y de licencias.

El software sin licencia vigente se desinstala automaticamente. El uso de
aplicaciones descargadas de fuentes no oficiales esta prohibido y se trata como un
incidente de seguridad.
